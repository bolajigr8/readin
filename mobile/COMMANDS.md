## 2. Check that everything is ready
flutter pub get
flutter analyze
flutter test
node tool/test_tap_zones.js          # reader tap zones (left/right turn, middle shows the bars)

## 3. Try it on your phone (USB debugging on)
flutter devices
flutter run --release -d <your-phone-id>

## 4. Build the APK
flutter build apk --release --split-per-abi
