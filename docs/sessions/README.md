# Session logs

One file per working session: `YYYY-MM-DD-<short-topic>.md` (add `-2` if there are several the same day).
Template:

```
# YYYY-MM-DD — <topic>
Stage: Sx        Started from: NEXT.md as of <date>
## Asked
## Decided (also copy to DECISIONS.md)
## Changed (files / areas)
## Tested (commands + results)
## Not done / not tested
## Next step
```
Commit these files (they are the project's memory). Never put secrets, tokens or personal data in them.
